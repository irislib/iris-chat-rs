DEMO ACCESS: AppStoreDemoUserMode
Enter this in the Name field when creating a NEW profile. No password is required. Iris Chat has no email/password sign-in or paid account tiers; every profile has access to all features. The submitted iOS build includes a demo with pre-populated content.

Start the demo (iPhone or iPad):
1. Start at the welcome screen and tap Create profile.
2. Enter AppStoreDemoUserMode in the field labeled "Name (optional)". The screen will confirm: "Demo profile with sample messages. A new secret key is created on this device."
3. Tap Accept Terms, then Create profile. Wait for "Preparing sample messages..." to finish. If preparation fails, tap Retry in the demo banner.
4. The chat list contains Sample conversation and Sample group. The bottom banner says "Demo profile · Sample messages". Open Sample conversation to see incoming/outgoing text and a playable six-second audio message. Play, pause, seek or change its speed; long-press messages for reactions and other actions. Use the microphone to record a voice message, or attach a photo/file. Sample group contains a group message.

If an earlier review profile is already open:
Renaming an existing profile does not enable the demo. To start over with a disposable review profile, tap the chat-list avatar → Settings → Account data → Delete all local data → Delete, then follow the steps above. This removes that device's profile, messages and keys; use it only for your test profile. Do not select Delete profile.

Live messaging, voice/video calls, CallKit and background audio:
Use TWO iPhones/iPads, each with its own newly created profile. You can enter AppStoreDemoUserMode on both; each creates a different user ID and secret key. No shared credentials are needed.
1. On the first device, open its profile from the chat-list avatar and copy its user ID. On the second device, tap New chat and paste that ID. Send a message, then accept the incoming message request on the first device.
2. In this live conversation, tap the phone or video icon. Allow microphone/camera access and answer on the other device. Exchange messages, attachments and voice recordings in either direction.
3. For incoming CallKit, allow notifications, background or lock the receiving device, then call it. For background audio, background or lock a device during an active call. End the call using the app or system controls.
4. Add the other profile to Sample group from its group details to test live group delivery.

Sample conversation is pre-populated history with an offline sample contact. It will not answer calls or reply to new messages. Use the live conversation between your two test devices for these features.

Guideline 5: China mainland has been removed from the app's available App Store territories. CallKit remains available in the other selected territories.
